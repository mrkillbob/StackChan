# Prepared remembered StackChan host

`remembered_pairing.py` supplies dedicated HomeLab `SQLiteStateStore` / `DeviceRegistry` authority for <approved-device-id>, exact microphone/speaker capabilities, CA digest, audio endpoint and certificate expiry. Its private SQLite extension gates authentication until correlated storage ACK. Pending state is persisted before issuance and revoked on service restart; host database stores only token hashes. Active records reject replacement enrollment until Forget. Authentication consults durable credential hashes on every request.

`remembered_pairing_worker.py` is the production user-operated service. Import, startup and help are inert. JSON-lines commands are exactly enroll, confirm, cancel, connect and forget. Protocol bodies and grants never cross this app protocol. The original endpoints remain /companion/pair and /companion/audio. Enroll starts a finite listener, requires Mac confirm plus physical Pair and Remember, sends the credential directly on the enrolled TLS socket, waits for storage ACK, commits authority, sends ready and closes without media. A lost final ready preserves committed trust. Failed Forget still attempts checked live-owner cleanup and blocks reconnect until revocation persistence is resolved. The app permits an explicit grant-only Forget retry and removes that cleanup issue only after the worker returns the fixed remembered_forgotten acknowledgement; audio cleanup remains retained. Original-call acknowledgement is available after completed enrollment without granting audio itself. Cleanup failures retain exact owners. EOF/SIGTERM closes app input then retries checked cleanup on the same owner with a short asynchronous delay; no new route is acquired. The remembered Mac process is never force-killed by the six-second timer. Only the fixed remembered_cleanup_verified acknowledgement clears shutdown audio/grant issues, and retained issues prevent successful app closure. Unexpected startup failure exits nonzero with sanitized failure status.

The Swift app's remembered disclosure supplies real Enroll, Confirm match, Connect and Forget on Mac controls. Its command arguments contain no token. It starts the candidate remembered worker only after a user click; a compiled candidate-source path identifies that worker. Existing temporary USB serial numeric pairing plus WSS audio remains separate. Default command-line numeric worker behavior retains legacy trust. Finite USB/native audio authorization is unchanged. Manual Connect and epoch-bound physical Listen remain mandatory. Actual gateway activity and bounded countdown are projected to sanitized app status.
