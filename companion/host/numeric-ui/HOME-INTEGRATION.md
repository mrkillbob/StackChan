# HomeLab / Apple integration boundary

Historical user scope selects Apple-first HomeLab Companion (native Siri/App Intents wrapper plus PWA character face) and HOOBS/HomeKit, with SmartThings only where needed as a device layer. Alexa was dropped. Existing wrapper `/Users/mikedemott/Homelab/clients/apple/Sources/Shortcuts.swift` supplies Open Companion, Mute, Unmute; it does not currently start/resume agent tasks through Siri. Existing `GatewayClient` and server own paired-device credentials and conversation/turn/approval contracts. No second app, gateway, account or authority database is added here.

The StackChan `home_companion.py` seam imports those exact HomeLab contracts. It takes an existing authorized device plus an existing selected conversation/turn/generation/external-session binding. It never creates a conversation, issues a token, selects a fallback agent, schedules an automation, notifies a room or executes a device command. Its default is unavailable. A synthetic reader supports offline room status and immutable review drafts only. A later verified HOOBS/HomeKit reader must map allowlisted accessories to rooms, bound freshness/results, expose verified transport availability, and reuse the already authorized HomeLab gateway rather than discovering devices or prompting for new permissions silently.

TV/LIFX drafts bind one selected room and immutable light targets, preserving the pre-dim levels for an explicit restore draft. They produce existing HomeLab `Approval` records with a revision hash and exact conversation/turn binding, dedupe a bounded number of request IDs, reject mismatched retries and stale/revoked sessions, and never execute. Live action plumbing must separately verify granted `home_control` scope, exact approved revision/expiry, generation, target membership, observed-state conflict handling and idempotency through HomeLab; pending draft approval is not authority.

Quiet hours use an explicit IANA timezone and half-open local intervals (including midnight wrap). A room must be chosen; blank/all-room action scope is rejected. UI or future notifications must respect this policy; no notification is sent by this module. TV/Netflix state requires a verified supported state reader; the offline fixture's Boolean is not a detected running app or a license to launch Netflix.

`agent_handoff.py` supplies a disabled Siri/task adapter seam with synthetic draft tests. Each draft preserves an explicitly selected existing Codex, Claude or Hermes conversation, turn, generation, external session reference and character identity. It requires the existing device's `agent_handoff` capability, refuses missing or stale bindings, has no fallback or conversation-creation API, and produces a pending review record without dispatch. Task text is excluded from object representations. A missing adapter remains unavailable even when a different agent exists.

Siri task/agent launch remains unwired: the Apple wrapper requires a reviewed HomeLab change, explicit target runtime/session selection, fresh per-session authority, and truthful availability for Codex/Claude/Hermes. Offline tests cover binding/policy/draft behavior; installed App Intents, agent dispatch, HOOBS pairing and real lights/TV operation remain unverified.
