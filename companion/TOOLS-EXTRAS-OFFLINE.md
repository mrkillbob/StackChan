# Recovered Tools scope and offline increment

The prior shortlist is recorded in `STOCK-SOFTWARE-INTEGRATION-PROPOSAL.md`, committed at650d6c3 on **2026-10-09 05:09:37 UTC**. It superseded the earlier Snake ordering: IR learn/SD remotes, NFC URL editor, bounded external-Grove UART Terminal, and touch2048 or Pong; Minesweeper was optional. `TOOLS-AGENTS-VERIFICATION.json` records the first IR/NFC/2048 implementation at1cedafd on **2026-10-09 06:31:18 UTC**, with hardware validation false. Those decisions and source are retained.

This increment extends the same Launcher → Tools → selection → dedicated page flow:

- Infrared now has Learned signal review and a Saved remotes library. Save copies a valid captured signal into one of eight RAM slots. Selecting a slot loads it for review; transmission still requires a separate Send once tap. Every record remains bounded to511 timings,15ms per timing and180ms total, with the existing38kHz single transmission. Closing Tools clears the library. No card is mounted or written.
- The native archive codec provides atomic all-or-nothing import/export for up to eight records and64KiB, rejecting invalid names, duplicates, integer overflow, timing/carrier mismatches and trailing input. Its versioned `STACKCHAN_IR_V1` format is **not** a Flipper `.ir` file or FAP loader. The SD store adapter explicitly reports unavailable. Import/export is currently a code seam with mock tests, not an on-device file picker.
- UART Terminal has a dedicated local echo demo and printable-text editor. Start is explicit; shutdown is requested by60s. Each send is at most64 characters plus LF, each read is at most64 bytes, and display history stays within1024 bytes. Back stops the session before navigating; failed shutdown remains visibly pending and blocks new starts and sends. A rejected write immediately attempts cleanup; mocked close failure retains ownership. The unavailable production adapter opens no GPIO/UART. Demo text identifies itself; it is not a hardware response. The configuration model accepts only explicitly selected Grove A/B/C and9600/38400/115200 baud, with no servoUART6/7 mapping.

No Flipper code or remote database is imported. Prior provenance pins remain in the proposal/source inventory: M5 BSP8d4d6fc3… MIT; xMasterX1066d17a… UART/2048 and Pong paths; optional Minesweeper3de0b724…. License verification is still required before importing any external implementation or data. No new app, daemon, gateway, marketplace download, credential or radio operation is added. Existing NFC URL editing/emulation and2048 remain intact.

Remaining qualification: exact SD wiring/mount and card handling; a bounded serialized SD store plus explicit save/load UI; external Grove electrical suitability and selected pins; a real nonblocking UART adapter with exact shutdown; current full SDK build; physical IR/NFC/UART/SD acceptance. Pong and Minesweeper remain optional candidates, not implemented claims. A separate Flipper device connection remains unverified.

The interactive `tools-preview.html` shows design states only. Portable model/UI checks do not prove physical operation. This increment is source-only until separately reviewed, built and explicitly approved for device activation.
