# Portable Stack-chan companion implementation

Michael requests full custom firmware in this existing fork. Default route: Stack-chan → the same Mira as coordination hub; Mira → authorized agents/tools. Robot may invoke an explicitly authorized home/device capability directly. Robot UI also selects Claude, Codex and Hermes with explicit identity/status. Natural bidirectional voice, interruption, vision, movement and authorized home integration are the target, at home or anywhere with internet. No cloned TTS or unrelated API session substitutes for Mira.

## Existing foundations and boundaries

Official M5Stack source 1b5765599fba8aaad1811d9a79358ccc7051f5f3 and its CoreS3 BSP/audio/servo/camera drivers remain the hardware base. Existing codec endpoint and host worker remain the audio worker. HomeLab c0d1181b235bf99fd03f71ec49c9dbae76007ef4 owns DeviceRegistry pairing/revocation, ConversationSessions/Turn request deduplication and generation, EventJournal and Approval. The existing StackChan integration imports these contracts; do not fork them into another authority service. Existing HomeLab code and its four local plans are unchanged.

Native Mira Voice owns the actual existing conversation, voice and memory. Public AUHAL bridges its OS audio devices; bridge epoch/turn metadata never claims to create or resume a Mira cloud conversation. Claude Code and Codex App Server adapters already exist in HomeLab but are separate identities, not Mira transport. Hermes discovery is explicit; route availability/model/included usage must be revalidated before use. Agent switch stops old transport output, invalidates its epoch, waits for real stop acknowledgement, and shows old/new provider, exact session and memory boundary. Never automatically fall back, copy another agent's memory, or label short-term robot state as Mira memory.

## Implemented slice

Native AUHAL output to Pro Tools Audio Bridge 2-A_UID and input from Pro Tools Audio Bridge 2-B_UID, with explicit per-instance device selection and channel-one mapping. Fixed 48kHz monoPCM16, preallocated callbacks, 160ms lock-free rings, counted drop-new overflow/zero-underflow, callback error mute, epoch-tagged stale rejection, half-duplex playback gate. Library load never opens IO; no global defaults or device rates changed. Python worker binding reuses existing Opus/resamplers/CodecHostBridge, splits larger worker PCM chunks. Firmware audio_session.hpp supplies acknowledged epoch, physical consent, direction sequence, heartbeat expiry and interruption policy with no NVS/IO side effects. Native library compile, concurrent ring, firmware-policy and native render-callback tests, worker load-only smoke PASS (VERIFICATION.json). This does not yet wire or build a new ESP32 streaming image.

## Portable connection and trusted-host contract

ConnectionHello identifies robot and protocol, advertised hardware capabilities and proposed provider/session; it grants no authority. TrustedHostGrant must bind verified host identity, revocable HomeLab device grant, exact capabilities, expiry and user approval. USB power alone grants no files, terminal, local network, microphone or camera access. CapabilityReport contains only resources granted by that host, never all discoverable resources. SwitchRequest carries request ID, target connection/session and expected generation. ToolRequest binds the same authority tuple plus immutable approved arguments. Resumption requires authentication, a new transport epoch and source-specific session acknowledgement; never replay tools/audio after reconnection.

For internet portability prefer already-authorized authenticated private connectivity, including existing Tailscale routes only after read-only route verification. No tunnel, firewall change, public listener, cloud endpoint, certificate trust change or new access is inferred. Robot offline mode is visible, muted and motion stopped; queued audio/tool actions expire. The companion host must remain reachable to bridge native Mira Voice. Robot-side Tailscale/remote wake or an arbitrary computer-host route is not presently implemented or claimed.
