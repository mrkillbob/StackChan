## Exact remaining owner interfaces

The new outbound module is a source proposal until accepted and wired to genuine authority and transport. Physical StackChan and desktop companion are distinct principals. - **Task8 desktop enrollment:** real no-dial registry lookup/watch, source-owned installation/socket identity, witness/signer/receipt transport and accepted common contracts; prepared UI alone does not create any binding.
